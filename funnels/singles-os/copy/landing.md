# SinglesOS: Landing Page Copy (for the trademark filing)

Updated 2026-11-03. This copy matches `design/singles-os.html` word for word.

Purpose: a short, live page that shows the **SinglesOS™** name in use with the services it covers, for the trademark filing. It is not a sales funnel: no dates, prices, program details or forms.

Decisions (2026-11-03):
- **Logo:** none exists, so the page uses a text wordmark ("Singles" ivory + "OS" gold italic, Playfair Display) with a small gold arch mark. A text-only version is fine if the attorney prefers plain text.
- **Services:** our best guess (education and coaching, which is what the Daniels already offer). The attorney can adjust the one services line.
- **Owner:** not needed on the page. The footer says "a trademark of its owner".
- **No waitlist or form.** Avoid "coming soon" or "waitlist" wording, since it suggests the services aren't offered yet. The only button scrolls to the services section.
- **Photos:** two solo shots side by side (Dharius: `daniels-7800.jpg`, Shameka: `daniels-7860.jpg`, cropped to match face size).
- **Domain:** to be confirmed.
